# Mini Launcher
Launcher básico (Kotlin + Jetpack Compose): lista de apps en cuadrícula, buscador y fondo con tu wallpaper.

## Compilar online
1. Sube todo el contenido a un repositorio de GitHub.
2. Pestaña Actions > "Build APK" > se ejecuta solo al hacer push (o "Run workflow").
3. Al terminar, descarga el artefacto "MiniLauncher-debug-apk" (zip con el .apk).

## Instalar
Instala el APK, pulsa Inicio y elige "Mini Launcher" > Siempre.
